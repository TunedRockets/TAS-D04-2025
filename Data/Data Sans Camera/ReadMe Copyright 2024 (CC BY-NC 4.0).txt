How to Use:
To access the data and files in this repository, navigate to the respective folders and explore the contents.
Description of the data is given below. For any questions or assistance, please contact the authors at s.a.pantoji@tudelft.nl.
Matlab data files (.mat) with reduced data have been made available for convenient data loading.
Fileformats : csv, text, tiff, mat.

1) AFP program straight line : KUKA robot program used for layup.

2) Laser tracker
- Straight lines :  Position data from the layup of the 31 tows.
- Straight lines traverse :  Position data from the traverse scanning of the 31 tows.
- XYZ reference : Position data from the X,Y,Z reference moves (before the experiment).
- XYZ reference after : Position data from the X,Y,Z reference moves (after the experiment).

3) Camera data
- Straight lines :  Camera data from the layup of the 31 tows. Ximea Camtool application can be used to view as video.
- Select images for algorithm calibration :  Camera data used as reference images.

4) LLS data
- Straight lines :  LLS scanner profile data from the layup of the 31 tows. Python API code used to record data. 
- Straight lines traverse :  LLS scanner profile data from the traverse scanning of the 31 tows.
